# 网盘真实下载地址解析功能 · PRD

> 状态：初稿（v1 范围待用户确认）
> 背景：乐乐下载器（Tauri2 + React18 + TS + Vite + Rust）拟增加「国内网盘真实下载地址自动解析」功能。
> 已确认需求三要素：① 平台=百度/阿里/夸克/123/腾讯微云/天翼 共 6 个；② 凭据由浏览器扩展自动读取已登录 cookie；③ 用户在 App 内粘贴「分享链接 + 提取码」触发解析。

---

## 1. 产品目标

让用户在桌面端粘贴国内网盘的分享链接（含提取码），一键解析出**真实可直接下载的直链**，交给现有多线程下载引擎下载，获得接近 IDM 的体验，免去各网盘网页版的限速与客户端依赖。

## 2. 用户故事

- 作为用户，我想把百度/阿里等网盘分享链接粘进 App，填提取码，点「解析」，看到文件名/大小/直链，点「加入下载」即开始高速下载。
- 作为用户，我不希望手动去网盘网页里抓 cookie / token，希望扩展自动用我已登录的浏览器身份完成鉴权。
- 作为用户，我希望解析失败或直链过期时有清晰提示，而不是静默卡住。

## 3. 可行性评估（按平台，基于 2026-08-11 WebSearch）

| 平台 | 解析所需凭据 | 可行性 | 限速 / 时效 | 备注 |
|------|--------------|--------|-------------|------|
| 百度网盘 | BDUSS / AccessToken（cookie） | ✅ 可行（受限） | 免费用户限速；直链数分钟~数小时失效 | 社区成熟（BaiduExporter、baidu-wangpan-parse）；2025 起推荐用 AccessToken 而非明文 BDUSS |
| 阿里云盘 | refresh_token | ✅ 可行 | 直链可用；大文件需特殊处理 | 开放 API（`file/get_download_url`、分享 API）；refresh_token 可由扩展读取登录态/storage |
| 夸克网盘 | cookie（pan.quark.cn） | ✅ 可行 | 直链可用 | `drive-pc.quark.cn/1/clouddrive/file/download?fid=` + cookie |
| 123云盘 | 公开分享可匿名；登录态更佳 | ✅ 可行 | 直链可用；VIP 大文件需账号 | 官方支持直链分享；亦有第三方解析 API 兜底 |
| 天翼云盘 | access_token + 签名 | ✅ 可行（较复杂） | presigned URL 约 600s | V3 API 需 timestamp/nonce/signature；有第三方 API 兜底 |
| 腾讯微云 | 无公开 API | ⚠️ 高风险 / 可能不可行 | — | 仅个别图片解析第三方；通用文件下载逆向脆弱，建议暂缓 |

## 4. 需求池

### P0（v1 必须）
- **R1 网盘解析面板 UI**：输入分享链接、输入提取码、平台自动识别、解析按钮、结果列表（文件名/大小/直链/有效期）、一键「加入下载」。
- **R2 扩展↔App 双向通道**：App 向扩展下发解析请求，扩展将直链回传 App（当前桥接仅扩展→App 单向）。
- **R3 百度网盘解析**（受限：免费限速，直链短时效）。
- **R4 阿里云盘解析**（需 refresh_token，扩展读取）。

### P1（v1 尽量覆盖）
- **R5 夸克网盘解析**。
- **R6 123云盘解析**。
- **R7 天翼云盘解析**（需 access_token + 签名算法）。
- **R8 直链过期/失败兜底**：提示「直链已失效，请重新解析」并支持一键重解。
- **R9 批量/历史解析**：记录最近解析的链接，便于重解。

### P2（后续）
- **R10 腾讯微云解析**（研究性，依赖逆向，可能不可行）。
- **R11 文件夹分享解析**（多文件）。
- **R12 会员提速**（如平台提供，不主动破解限速）。

## 5. UI 设计稿（文字描述）

新建「网盘解析」标签页/面板：
```
[ 分享链接输入框: https://pan.baidu.com/s/xxxx                ]
[ 提取码输入框: xxxx        ]  [ 平台: 自动识别 ▾ ]  [ 解析 ]
─────────────────────────────────────────────────
解析结果：
  ☑ 文件名.mp4   1.2 GB   直链有效至 12:30   [加入下载]
  ☑ 文件名2.zip  340 MB   直链有效至 12:31   [加入下载]
[ 全部加入下载 ]
```
- 平台自动识别：根据链接域名匹配；可手动覆盖。
- 「加入下载」调用现有下载引擎（直链 + 必要请求头如 Referer/UA/Cookie）。

## 6. 推荐分阶段范围

- **v1（建议先做）**：百度、阿里、夸克、123、天翼 5 个（均已有可行路径）。
- **v2 / 研究**：腾讯微云（高风险，先做技术验证，失败则放弃）。

理由：百度虽限速但用户价值最高；阿里/夸克/123/天翼均有可用接口；腾讯微云无公开方案、逆向脆弱，不阻塞 v1。

## 7. 待确认问题（需用户拍板）

1. v1 范围是否接受「腾讯微云暂缓」？
2. 解析逻辑放哪：**A. 扩展内解析（仅回传直链，cookie 不出行）** ⭐推荐 / B. App(Rust)内解析（扩展仅提供 cookie，逻辑集中但 cookie 需传给 Rust）？
3. 百度免费用户限速是否接受（本质为平台限制，等同官方客户端，无法突破）？
4. 天翼/微云等是否接受**依赖第三方解析 API**（如 52api/ffapi）作兜底，还是只走官方逆向？

## 8. 关键约束与合规

- 灰产边缘，**仅限个人使用**，遵守各网盘服务条款与版权规定。
- cookie / token 属敏感信息：**不得落盘持久化**；优先方案 A（扩展内解析仅回传直链）。
- 直链具时效性，必须有过期/失败兜底与重解机制。
- 不主动破解平台限速机制（仅获取平台下发的直链）。
